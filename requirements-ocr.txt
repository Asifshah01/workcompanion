#
# WorkCompanion falls back to OCR when a PDF page yields too little text
# (see OCR_MIN_CHARS_PER_PAGE / OCR_MAX_PAGES in .env.example). Without these
# packages a scanned PDF simply indexes as empty and says so, rather than
# failing silently.
#
# Tesseract itself is a system binary:
#   Windows:  winget install UB-Mannheim.TesseractOCR
#   macOS:    brew install tesseract
#   Debian:   apt-get install tesseract-ocr
#
# Streamlit Cloud already provides it via packages.toml.
